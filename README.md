```text

```

後台、LIFF、n8n workflow、部署前檢查都以這個資料夾為準。不要再使用或重建舊的重複資料夾。

LINE OA 設定資料庫：


## 關於本網站

本網站為北屯耀進 曾咨耀服務處官方線上服務平台，提供北屯區市民以下服務：

- 線上陳情案件申請
- 陳情案件辦理進度查詢
- 地方會勘建設紀錄
- 國會質詢與提案資訊
